# 第2種電気工事士 暗記カードアプリ

第2種電気工事士試験の「写真鑑別」「図記号鑑別」を学習するための、ブラウザだけで動くスマホ向け暗記カードアプリです。ビルド不要・依存ライブラリなしの単一HTMLアプリで、初回起動時に310枚のカード(名称・役割・写真・配線図記号)が自動で使えるようになります。

## ファイル構成
```
index.html       アプリ本体
cards_data.js    プリインストール済みカードデータ(310枚・画像込み、約4.5MB)
sample_cards.csv 追加でCSVインポートする場合のフォーマット例
```

`index.html` は `cards_data.js` を同じフォルダから読み込みます。**2ファイルは必ず同じ階層に置いてください。**

## GitHub Pagesで公開する

1. このリポジトリをGitHubに作成し、このzipの中身(index.html / cards_data.js / sample_cards.csv)をルート直下にそのままpush
2. リポジトリの **Settings → Pages** を開く
3. "Build and deployment" の Source を **Deploy from a branch** にし、Branch を `main` / `/(root)` に設定して Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリにアクセスできます

## ローカルで試す
ダブルクリックで `index.html` を開くだけで動作します(サーバー不要)。

## 主な機能
- 6方向の出題モード(配線図記号⇄名称、写真⇄名称、役割⇄名称)
- おまかせ学習・今日の復習・カテゴリ別・苦手カード・未学習カード
- 忘却曲線に基づく復習間隔の自動調整(正解:1→3→7→14→30→60→120日、不正解:1→1→3→7日)
- カードのタップで解答表示、左右スワイプ(またはボタン)で正解/不正解を記録
- アプリ内での新規カード追加(名称・役割はテキスト入力、写真・配線図記号は画像アップロード)
- CSVでのカード一括インポート + 画像の一括/個別アップロード
- 学習データのJSONバックアップ書き出し・復元

## データの出典と注意
プリインストールされているカードは「第2種電気工事士すい〜っと合格 写真・図記号の暗記カード」(オーム社)から、名称・役割・画像を抽出して作成しています。画像には元資料の著作権表示(©Ohmsha)が写り込んでいるものがあります。個人の学習目的でご利用ください。

## 技術的な設計
- カードマスターデータ・学習履歴・画像は別々に保存しており、カード内容を更新しても学習履歴は消えません
- 出題方向は `QUESTION_MODES` 配列に追加するだけで拡張できる構造です
- 復習アルゴリズムは `ReviewScheduler` として独立したモジュールにしてあり、UIやデータ層に影響を与えずに差し替え可能です
