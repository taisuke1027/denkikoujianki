# 第2種電気工事士 暗記カードアプリ

第2種電気工事士試験の「写真鑑別」「図記号鑑別」を学習するための、ブラウザだけで動くスマホ向け暗記カードアプリです。ビルド不要・依存ライブラリなしの単一HTMLアプリです。

プリインストールカードが113枚含まれています。CSVインポート、またはアプリ内の「＋新規カードを追加」から、自分でカードを追加していくこともできます。

## ファイル構成
```
index.html       アプリ本体
cards_data.js    プリインストールされたカードデータ(113枚・画像込み)。index.htmlと必ず同じフォルダに置いてください
icon.png         共有シート・ホーム画面追加・ブラウザタブに表示されるアプリアイコン。index.htmlと同じフォルダに置いてください
sample_cards.csv 追加でCSVインポートする場合のフォーマット例(任意)
```

⚠️ `index.html` と `cards_data.js` と `icon.png` は3ファイルセットです。すべて同じフォルダにダウンロードしてから `index.html` を開いてください。

## GitHub Pagesで公開する

1. このリポジトリをGitHubに作成し、`index.html`・`cards_data.js`・`icon.png`(と使う場合は`sample_cards.csv`)をルート直下にそのままpush
2. リポジトリの **Settings → Pages** を開く
3. "Build and deployment" の Source を **Deploy from a branch** にし、Branch を `main` / `/(root)` に設定して Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリにアクセスできます

## ローカルで試す
ダブルクリックで `index.html` を開くだけで動作します(サーバー不要)。

## データの保存について
カード・学習履歴・画像はすべてブラウザの **IndexedDB** に保存されます。ページを閉じたり、端末を再起動しても、同じブラウザ・同じサイトを開けばデータはそのまま残ります(ブラウザのキャッシュ削除やシークレットモードでは消える場合があります)。

端末を変える場合や、念のためのバックアップには、設定画面の「バックアップ書き出し」でJSONファイルとして保存し、別の端末で「バックアップ復元」から読み込んでください。

## 主な機能
- 6方向の出題モード(配線図記号⇄名称、写真⇄名称、役割⇄名称)
- おまかせ学習・今日の復習・カテゴリ別・苦手カード・未学習カード
- 忘却曲線に基づく復習間隔の自動調整(正解:1→3→7→14→30→60→120日、不正解:1→1→3→7日)
- カードのタップで解答表示、左右スワイプ(またはボタン)で正解/不正解を記録
- アプリ内での新規カード追加・編集・削除(名称・役割・カテゴリはテキストで、写真・配線図記号は画像アップロードで登録)
- カテゴリの自由追加、お気に入り登録
- CSVでのカード一括インポート/書き出し + 画像の一括/個別アップロード
- カード一覧の検索・カテゴリ絞り込み・お気に入り絞り込み・未登録項目絞り込み
- 学習データのJSONバックアップ書き出し・復元
- 学習履歴のリセット

## GitHubを更新したときにホーム画面のアプリにも反映させる
`cards_data.js`の中身を変更したら、ファイル先頭の`window.DEFAULT_DECK_VERSION`の数値を1つ増やしてからpushしてください。ユーザーがアプリ内で編集していないカードだけ、次回起動時に自動的に最新内容へ同期されます(編集済みのカードや学習履歴は保持されます)。

## 技術的な設計
- カードマスターデータ・学習履歴・画像は別々に保存しており、カード内容を更新しても学習履歴は消えません
- 出題方向は `QUESTION_MODES` 配列に追加するだけで拡張できる構造です
- 復習アルゴリズムは `ReviewScheduler` として独立したモジュールにしてあり、UIやデータ層に影響を与えずに差し替え可能です
